# Ahmed Result Interactive Page

A fun interactive HTML page that reveals Ahmed's exam results through playful UI, animations, and a simple drag-and-drop puzzle.

## 🚀 What this project does

- Presents a welcome card in Arabic with animated stars and glowing effects.
- Includes a playful "Yes / No" button interaction with moving buttons and message popups.
- Unlocks a drag-and-drop mini puzzle to reveal the result page.
- Shows a final result table with exam grades, progress bars, confetti, and celebratory audio effects.

## 📁 Files

- `index.html` — the  HTML code.
- `style.css` — the  css code.
- `script.js` — the  js code.

- `images.jfif` — the placeholder frame image shown in the puzzle drop area.


## 🎮 How to use

1. Open `index.html` in any modern browser.
2. Click the pink button labeled `ايوه عايز أشوف 👀` to start the interaction.
3. After a few playful popups, you will be asked to solve the puzzle.
4. Drag the image of Ahmed into the frame to reveal the final results.

## ✨ Features

- Animated background stars and glowing card effects
- Button motion and popup messages for a humorous experience
- Pointer-based drag-and-drop support for desktop and touch devices
- Confetti celebration when the result is revealed
- Built-in progress bars and result summary table

## 🧩 Interactive puzzle

The page includes a drag-and-drop zone where the user must move Ahmed's image into the frame to unlock the final result.
